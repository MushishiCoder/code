根据完全二叉树中孩子与双亲结点的数学关系（双亲编号为i，左孩子为2i，右孩子为2i+1，任意结点双亲为[i/2]），设计一个递归函数，输入两个结点编号a和b，寻找并输出它们在二叉树中的最近共同祖先。
运用的函数的递归调用：一个函数在它的函数体内直接或间接地调用自己，这个函数就叫递归函数。


递归的本质：就是函数在不断地调用自己。每一次调用，计算机都要为这个新调用的函数开辟一块临时的内存空间（存它的参数、局部变量、返回地址），这就好比往栈里叠一个新盘子。
为什么要用栈：因为函数必须按照“谁最后调用，谁先算完”的顺序往回退（先进后出）。
什么是“栈溢出”：如果你写了一个没有出口的死递归（或者递归太深了），计算机就会无休止地往桌子上叠盘子，直到把桌子堆满、内存耗尽，这就叫栈溢出（Stack Overflow）
