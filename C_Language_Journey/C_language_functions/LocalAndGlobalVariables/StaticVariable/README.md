在函数aust()中定义了一个局部变量和一个静态局部变量，通过循环进行三次函数调用，观察程序运行过程中这两个变量的值有什么不同。
auto:普通局部变量,它是“随用随创建，用完就销毁”的（具有自动存储期）。每次进到aust()函数里，它都会重新被创建并初始化为0。虽然临走前它自增变成了1，但函数一退出，内存就被收回了。等第二次调用时，它又是一个崭新的、值为0的变量。
static:静态局部变量,它的生命周期是贯穿整个程序运行期间的，只在程序刚开始时初始化一次，退出函数后不会被销毁，里面的数值会被永久保留。第一次调用时它是0，走的时候自增成了1；当第二次调用时，它不会重置为0，而是带着上一次留下的1进入函数。打印出来是1，然后又自增成了2。
