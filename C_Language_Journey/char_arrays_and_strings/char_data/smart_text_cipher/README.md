题目背景:
某文本处理软件在接收用户输入时，经常因为输入流中的“残留回车”导致数据读取错乱。同时，系统需要对输入的混合字符进行分类统计，并对满足特定条件的英文字母进行加密和大小写反转处理。题目要求请编写一个完整的C语言程序，实现以下功能：
1.安全读取：首先通过键盘输入一个正整数n（表示后续要输入的字符个数，假设1<=n<=100）。随后要求程序能够完美跳过数字n之后残留的回车符，准确无误地连续读取n个字符（字符可能包含字母、数字、空格或其他可见字符）。
2.字符分类统计（使用 <ctype.h> 库函数）：
    统计其中英文字母的总个数。
    统计其中十进制数字（'0'~'9'）的总个数。
    统计其中其他字符（既不是字母也不是数字的符号或空格）的总个数。
安全加密与大小写反转：
    对读取到的每一个英文字母进行处理：
        大小写反转：如果是大写字母，利用库函数将其转为小写；如果是小写字母，将其转为大写。
        安全向后加密：将转换后的大小写字母在字母表中向后移动3位（即ch=ch+3）。
        防溢出与循环处理：为了避免前面学过的char类型溢出和越界问题，请在代码中妥善设计逻辑（例如使用更大的整型int暂存计算结果，或者处理超过'z'/'Z'时的循环回退-26），确保字母表能够像圆环一样正确循环（例如'z'加3变成'c'，'Z'加3变成'C'）。、

输出结果：
输出统计好的字母数、数字数、其他字符数。输出加密并反转大小写后的最终字符串。
