编写一个C语言程序，实现通过调用函数来修改主函数中一维数组的内容。具体要求如下：
1.定义一个宏常量N表示数组的最大容量（如20）。
2.在main函数中，提示用户输入实际需要操作的元素个数n，并通过键盘依次输入n个整型数据存入数组中。
3.将输入的原数组内容按格式打印输出。编写一个名为ModifyArr的函数，该函数接收数组及实际元素个数n，在函数内部直接对数组的每个元素进行修改（例如将每个元素的值扩大为原来的10倍）。
4.在主函数中调用ModifyArr函数，并在调用前后印证“地址传递”的效果，输出数组被修改后的内容。


核心知识点

1. 地址传递机制：
   - 数组名作为实参传给函数时，传递的是数组首元素的地址。
   - 子函数通过指针/地址直接进入内存修改原数组，因此函数执行完毕后，主函数中的原数组内容会发生实质性改变。
2. 动态元素个数控制：
   - 结合用户输入的实际有效个数n进行循环读写，避免越界访问。
