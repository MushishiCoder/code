编写一个 C 语言程序，实现将一维数组作为函数参数传递。具体要求如下：
1.定义一个宏常量 N 表示数组最大容量（如 10）。
2.在 main 函数中定义一个大小为 N 的整型数组，通过键盘输入实际需要操作的元素个数n以及具体的数组元素。
3.编写一个名为 SumArr 的求和函数，该函数接收数组及实际元素个数n，计算并返回该数组前n个元素的累加和。
4.在主函数中调用 SumArr 函数，并将计算出的总和结果输出到屏幕上。


核心知识点

1. 数组名即地址：在函数调用时，传递数组名 `a` 本质上是将数组首元素的内存地址传给被调函数。
2. 形参与实参的区别：
   - 定义函数时形参写作 `int array[]`（方括号可留空）。
   - 调用函数时直接使用数组名 `a`，切勿加方括号 `[]`。
3. 结合元素个数（n）使用：由于传参只传递首地址，必须同时传入元素的实际个数n，以保证函数能正确控制循环边界，提高通用性。
