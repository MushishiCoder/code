核心任务：输入一行字符（以回车结束），统计所有英文字母（不区分大小写）在字符串中的使用频率。
输入格式：输入任意一行字符，以回车换行符结束。
输出格式：依次输出从 a 到 z 每个字母出现的次数，输出格式形如'count of a is X'

# 字母使用频率统计

## 算法思路
1. **字符读取**：使用 `while` 循环配合 `getchar()` 逐个读取输入的字符，直到遇到换行符 `\n` 结束。
2. **大小写统一**：利用条件判断检查字符是否为大写字母（`A` 到 `Z`），如果是则通过 `ch += 32` 将其转换为对应的小写字母。
3. **下标映射与计数**：
   * 定义一个大小为 50（实际只需 26）的计数数组 `a` 并初始化为 0。
   * 利用表达式 `ch - 'a'` 将小写字母精准映射到数组下标 `0 ~ 25`，每出现一次对应计数器自增 1（`a[ch - 'a']++`）。
4. **完整输出**：通过 `for` 循环从 `0` 到 `25` 遍历整个统计数组，利用 `i + 'a'` 还原出对应的字母，完整打印出所有 26 个字母的出现次数。

## 代码结构
* `main()`：控制整个字符的读取、大小写转换、频次统计以及最后 26 个字母频率的格式化输出。

## 知识点总结
* **字符与 ASCII 码的转换**：利用字符的整型特性实现巧妙的下标映射。
* **计数数组的应用**：通过空间换时间的思想统计频率，避免了复杂的查找与排序。
