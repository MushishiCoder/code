输入一个一维整型数组（包含n个元素），对数组元素进行去重并从小到大排序后输出。

# 数组去重与排序（方法二：计数数组/下标映射法）

## 算法思路
1. 空间换时间：定义一个足够大的全局计数数组（如 `int a[10000] = {0}`）。
2. 下标映射：将输入的每个数字直接作为统计数组的**下标（Index）**，每出现一次就让对应格子的值自增（`a[num]++`）。
3. 自动排序与去重：
   * 去重：由于只统计“是否出现过”，相同数字无论输入多少次，对应的格子值都大于 0。
   * 排序：从小到大扫描整个计数数组，只要格子值不为 0，直接打印该下标，天然实现升序和去重。

## 代码结构
* `main()`：负责读取个数并通过 `while(n--)` 循环统计频次。
* `PrintIndex()`：负责遍历整个计数表，将非零对应的下标打印出来。

## 适用场景
适用于数据取值范围较小（如 0~9999 之间）、追求极高运行效率的海量数据处理场景。
