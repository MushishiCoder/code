输入一个一维整型数组（包含n个元素），对数组元素进行去重并从小到大排序后输出。

# 数组去重与排序（方法一：排序去重法）

## 算法思路
1. 排序：先使用双重循环对输入的数组进行冒泡排序（或选择排序），使其从小到大排列。
2. 去重遍历：遍历排好序的数组，利用 `if (i == 0 || x[i] != x[i-1])` 的逻辑跳过相邻的重复元素。
3. 格式化输出：使用计数器控制每行打印固定的元素个数（如每行 10 个），保持排版整齐。

## 代码结构
* `InputArr()`：负责读取输入的数组元素。
* `SortArr()`：负责将数组从小到大排序。
* `PrnArr()`：负责去重并按格式打印输出。

## 适用场景
适用于元素大小无限制、但数据量相对较小的通用排序去重场景。
