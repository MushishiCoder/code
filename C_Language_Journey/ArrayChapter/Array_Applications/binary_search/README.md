小明最近在玩一个寻宝游戏。地上有一排按从小到大升序排列的宝箱，每个宝箱上都有一个正整数编号（可能有重复）。现在给出一个目标幸运数字 $x$，请你帮小明用二分搜索的方法找出这个数字在宝箱排队中的位置。
输入格式:第一行输入两个整数n和x(1<=n<=100，分别表示宝箱的总个数和目标幸运数字)。第二行输入n个已经按升序排好序的整数，代表各个宝箱的编号。
输出格式:如果找到了目标数字x，输出它在数组中的下标（若有多个相同数字，返回其中一个即可）。如果没找到，输出-1

递归二分搜索：按照升序排序好后，通过计不断地算中点mid将搜索区间对折，并与要找的数进行比较，确定该数的位置。
优点:在处理大规模数据的时候相对于顺序查找效率更高.
