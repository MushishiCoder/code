从键盘读入一个正整数n（1<n<10），再读入n个整数存入一维数组a中。利用比较交换排序法将这n个整数按从小到大的顺序（升序）重新排列，并输出排序后的数组。

比较交换排序法:
想象一下，班里有n个同学按高矮排成一排，你想把他们按从矮到高（升序）重新排好。第一轮（i=0）：让最左边第一个同学（a[0]）当擂主，拿着自己和后面所有的同学（a[1] 到 a[n-1]）依次比拼。如果后面有人比他矮，两人就立刻交换位置。这样一路比下来，当第一轮结束时，全场最矮的那个人就会被硬生生“换”到最左边的 a[0] 位置上。
第二轮（i = 1）：最左边的位置已经稳了，接着让第二个同学（a[1]）当擂主，和剩下的人比拼，把次矮的人换到 a[1]。以此类推，经过n-1轮比拼，整个数组就排好序了。
