假设我们在主函数中有以下基础变量定义：
int x = 10;
int y = 20;

//四种不同形态的指针定义：
int *p1=&x;                   // 类型A
const int *p2=&x;             // 类型B
int * const p3=&x;            // 类型C
const int * const p4=&x;      // 类型E


请判断下面给出的8个独立操作（每个操作互不影响），哪些会编译报错，哪些能正常运行：
*p1=15;
p1=&y;

*p2=15;
p2=&y;

*p3=15;
p3=&y;

*p4=15;
p4=&y;

对会编译报错的程序进行加//来保证程序通过
