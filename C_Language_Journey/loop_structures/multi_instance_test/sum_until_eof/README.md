计算n个整数求和。本题为多实例测试（包含多个测试实例），且没有给定总测试组数，也没有特殊的结束标志。程序需要一直处理输入，直到遇到文件结束符（EOF）为止。
输入格式：输入包含多个测试实例，每个实例占一行。每行先是一个整数n，接着是n个整数。
输出格式：对每个测试实例，输出n个整数的和。
核心知识点：EOF 与 scanf 返回值
EOF（End of File）：文件结束标志，在 C 语言中通常被定义为 -1。
scanf 的返回值：
当成功读取变量时，返回成功读取的变量个数。
当读到文件末尾或输入结束时，固定返回 EOF。
利用 while(scanf("%d", &n) != EOF) 可以完美实现“检测不到结束就一直死循环运行”的效果。
按crtl+z并回车，终止运行
